# Changelog

## 0.0.1 — preview candidate

- Visual Studio-specific out-of-process language-server adapter.
- Bundled, checksum-verified Windows x64 native diagnostics.
- Status, rescan, and restart commands in the Extensions menu.
- Explicit server override setting, refreshed on connection restart.
- Native-only runtime policy and safe process lifecycle handling.
- Locked dependency restore, Windows tests, protocol smoke, and VSIX audit.

Marketplace publication is pending host installation testing and the release
checks in [docs/publishing.md](docs/publishing.md).
