# Security

Follow the [Harness Lens security policy](https://github.com/harness-lens/harness-lens/blob/main/SECURITY.md)
for private vulnerability reporting. Do not post secrets, private harness files,
or raw provider output in public issues.

This preview bundles a native process. Its SHA-256 is checked before launch;
an explicit custom path executes the binary selected by the user. Optional
runtime providers are unavailable. Report any bypass of those boundaries.
